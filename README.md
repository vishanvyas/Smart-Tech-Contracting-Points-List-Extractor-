# Smart-Tech-Contracting-Points-List-Extractor-
A Python-based tool that automatically extracts BAS points tables from IFC drawing PDFs, organizes them by equipment type, optionally expands point data from submittals, and exports a standardized TATSU Excel points list. Built with Streamlit, PyMuPDF, pandas, and openpyxl, with all processing performed locally for data security.
